# シャッフル・ダンジョン

因果律崩壊型・5分サクッとローグライクRPG。出発前に、主人公と5体の敵のステータス、そして行動の対象（じぶん/あいて）をシャッフルし、配られた手札でターン制バトルを勝ち抜く。ストーリーは極薄、リプレイ性重視。

スマホでの隙間時間プレイを想定した Web ブラウザゲーム。

## 遊ぶ

https://bizyutyu.github.io/shuffle-dungeon/ （準備中）

## 技術スタック

- **Vite + TypeScript**
- **Phaser 4.2.1**（キャレットなし完全固定）。当初はチュートリアル・実務事例の蓄積量を優先して 3 系を選んでいたが、このゲームが使う API の範囲では移行の影響が小さい（`setTintFill` の置き換えのみ）と確認できたため 4 系へ移行した
- デプロイ: GitHub Pages（GitHub Actions 経由）

## アーキテクチャ

`src/core/` はゲームロジック（ステータス/対象のシャッフル・ターン進行・ダメージ計算・レリック効果・スコア集計）を Phaser に一切依存しない純粋 TypeScript として実装している。これは Phaser の一般的な構成ではなく、本作特有の設計判断:

- 本作の面白さの核はシャッフル後の数値バランスであり、描画なしで Vitest から高速に反復・シミュレーションできることが開発速度に直結する
- 乱数は `Math.random()` を使わず、シード付き決定論的 RNG（mulberry32）に統一している。同じシードで同じランが再現できるため、シード共有によるスコアアタックやデイリーチャレンジを後から無理なく追加できる

## 開発

```bash
pnpm install
pnpm dev            # ローカル開発サーバー
pnpm dev:host       # LAN 経由でスマホ実機から確認
pnpm typecheck
pnpm lint
pnpm test
```
